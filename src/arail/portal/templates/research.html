      📖 How the loop works
    
    
    
    Set a goal and the Researcher plans testable hypotheses, matches each
       to a measurable experiment archetype, runs them on this machine, and
       writes an honest report — every number is measured, could-not-run, or
       unmeasured. Never invented.

    How Autoresearch actually works
    
    
    
      It's not a task-runner ticking off a checklist. It's a small learning
      loop — try an idea, actually measure it, write down the honest
      answer, then do it again with what it just learned.
    
    

    
      
      
    1. 
        🧠
        
      
          1. Plan
          
      Your goal becomes a handful of testable ideas — not just one
             guess. You can see which ideas it picked and which it set
             aside, and why.
      
        
      
      
      2. 
      
    2. 
        🎯
        
      
          2. Design
          
      Each idea gets matched to something that can actually be
             measured on your machine — model speed, prompt quality,
             how well your Knowledge Base answers a question. No idea
             runs without a real way to check it.
      
        
      
      
      3. 
      
    3. 
        ▶
        
      
          3. Run
          
      The experiment runs for real, locally. If it can't run yet
             — no model loaded, nothing to measure against — it says so
             plainly instead of inventing a number.
      
        
      
      
      4. 
      
    4. 
        📋
        
      
          4. Report
          
      The result gets written to the Knowledge Base labeled
             measured, not run, or unmeasured —
             so you always know what's a real number versus what's just
             the model's commentary on it.
      
        
      
      
      5. 
    
    

    
    
      The point isn't more experiments — it's not being wrong.
      A result only counts if it was actually measured. Nothing here
      fabricates a win to look productive; a plateau or a "couldn't test
      that" is reported just as plainly as a success.
