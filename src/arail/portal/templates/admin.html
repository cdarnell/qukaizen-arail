Help & Reference

Common Commands

./arailctl start       # launch all services
./arailctl stop        # stop all services
./arailctl restart     # quick bounce
./arailctl update      # check & apply updates
./arailctl version     # show component versions
./arailctl status      # what's running
./arailctl logs        # tail activity log (all)
./arailctl logs browser    # browser events only
./arailctl logs researcher # research events only

Setup & Configuration

./arailctl setup       # first-time setup
./arailctl doctor      # validate environment
./arailctl reset full  # factory reset (careful!)
./arailctl pkb compile # rebuild knowledge base

Environment

All configuration lives in .env at the repo root. Key settings: MODEL_BACKEND, MODEL_NAME, ARAIL_MODE, LAB_ACTIVE_HOURS, LAB_HEAVY_HOURS.

Edit in the terminal tab or directly in your editor.

Updating Components

Run ./arailctl update to check all components. Use --check for a dry run. Update a single component with --component open-notebook.

Components are tracked in components.json.

Airgapped vs Hybrid

Click the mode badge in the nav to toggle. Airgapped: zero network calls, fully local. Hybrid: agents can browse the web (with your approval per domain).
