Open Studio only with the restricted browser

Opening Studio in a normal browser makes about 16 non-loopback requests (npm version lookups and one models.dev logo). That breaks the airgapped promise, so this page deliberately has no link to it. Use:

./arailctl mastra open

It starts a separate browser profile configured to refuse every address other than 127.0.0.1 / localhost (name lookups are mapped to "not found" and other connections go to a dead local proxy). In our measurements this produced no DNS lookups and no outside connections, but a packet capture has not yet confirmed it on every machine. Studio's page still attempts the requests; they are refused locally.
