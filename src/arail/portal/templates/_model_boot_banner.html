{# Boot model-selection banner (included by _nav.html on EVERY page, right after _model_switcher.html). Answers two questions in plain language: which model loads into GPU/memory now (slot A), and which model aeroLLM should reference for deep answers (slot B) — showing size, on-filesystem presence, RAM fit, and an install command / HF link when a candidate is missing. Modes (from GET /api/models/boot): • hidden — settled once (model_defaults.yaml exists) and healthy; render nothing. • picker — never settled yet; show the full two-slot picker immediately. "Confirm" writes model_defaults.yaml via POST /api/models/settle. "Not now" dismisses for this browser tab only (sessionStorage, keyed to the server's settlement stamp — a new stamp, e.g. after the picker was confirmed elsewhere or a config change, un-dismisses it). • problem — settled but something broke since (the configured model vanished from disk/Ollama, no longer fits, or .env drifted away from what was settled): a compact strip with "Fix…" (expands into the same full picker, pre-filled) and "Dismiss". Fetch-once by design: one GET on page load, no polling, no SSE — the lab's quiet-boot contract (see _boot_overlay.html's docstring) applies here too. "Fix…" and "Confirm" are the only other network calls this file ever makes, both user-initiated. All styling via v2 tokens — no literals, no style=. #}
